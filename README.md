# C/C++ 코딩 노트

C/C++를 처음부터 배워 프로그래머스 Lv.3까지, 그리고 임베디드 C/C++까지 가는 스터디 노트입니다.

- **노트 보기:** https://claude.ai/artifact/Va8eWowGk6n3oAG4tPhQUN
- 완성된 챕터: 0장(공부법), 1장(첫 프로그램과 출력), 2장(변수와 자료형), 3장(연산자). 나머지는 이어서 제작 중.
- 조립된 페이지: `dist/index.html` (브라우저로 바로 열 수 있음)

## 폴더
| 경로 | 내용 |
|---|---|
| `chapters/` | 챕터별 HTML (섹션 하나씩) |
| `dist/index.html` | 챕터를 합친 노트 페이지 |
| `STYLE.md`, `OUTLINE.md`, `specs/` | 작성 규칙, 전체 커리큘럼, 챕터별 설계서 |
| `meta.tsv` | 프로그래머스 문제 목록(번호, 현재 제목, 레벨) |
| `tools/` | 검증·조립·저장 스크립트 |
| `HANDOFF.md`, `STATUS.md` | 제작 인수인계 문서와 진행 상황 |

프로그래머스 문제 원문은 저작권 때문에 포함하지 않습니다(`tools/build_problem_bank.py`로 다시 받을 수 있음).
