## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 패턴 지도: 문제 신호 → 알고리즘 매핑표(예: '최소 시간 + 범위가 매우 큼 → 이분 탐색', '가중치 없는 최단 거리 → BFS', 'n ≤ 10 모든 경우 → 완전탐색', '구간 갱신/합 → 누적합/차분', '선택의 연속 + 최적 → DP 또는 그리디', '빈도/존재 → 해시'). 각 행에 해당 챕터 링크.
2. 제한사항으로 알고리즘 고르기(12장 표 복습)와 실제 예.
3. 시험장 루틴: 전체 훑기, 쉬운 것부터, 시간 배분(회사마다 형식이 다르므로 일반론), 막히면 부분 점수(정확성/효율성), 제출 전 엣지 체크.
4. C++ 시작 템플릿: 자주 쓰는 헤더(<bits/stdc++.h>는 g++ 전용 — 장단점), using ll = long long; 정도의 최소한의 별칭(매크로 남용 주의), 자주 쓰는 코드 조각 목록(부록 A 연결) — 외우기보다 이해해서 다시 쓰기.
5. 실수 체크리스트(오버플로, 초기화, 인덱스, 빈 입력, 출력 형식, 전역 변수 재초기화, 반환 타입).
6. 입출력형 대비: 다른 시험/백준 형식(입력 파싱, 빠른 입출력, 여러 테스트 케이스), 템플릿.
7. 연습처(일반론): 프로그래머스(많은 기업이 사용), 삼성 SW 역량 테스트 대비 SW Expert Academy, 현대자동차그룹 Softeer, 백준(입출력형), LeetCode(영문). '형식은 해마다 바뀌니 채용 공고를 확인' 명시.
8. Lv.3 기출 훈련 세트(아래 문제들) — 각 카드에 '어떤 패턴인지'를 힌트 1로.
9. 다른 사람 풀이 공부법, 오답 노트 템플릿(.box), 2주 복습 루틴.
10. 임베디드 직무 코딩테스트/면접 특징: C/C++ 선택, 비트·포인터 문제, 면접 즉석 코딩(링 버퍼, 문자열 뒤집기, 비트 세기) → 29–31장으로 연결.
