## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 펌웨어 실행 구조: 슈퍼 루프, 타이머 인터럽트 기반 주기 실행(1 ms tick + 플래그), 협조적 스케줄러(태스크 테이블), RTOS 개념(태스크, 우선순위, 세마포어/큐 — FreeRTOS는 이름만), 차량 ECU의 주기 태스크(AUTOSAR는 이름만).
2. 상태 머신: enum + switch, 상태 전이 표, 이벤트 처리 — 로봇 모드(IDLE → HOMING → RUN → FAULT), 버튼 디바운스 상태 머신(시뮬레이션 입력으로 run 검증).
3. 고정소수점: Q 포맷(Q15, Q16.16), 곱셈 후 시프트, 포화 연산, FPU 없는 MCU에서 쓰는 이유, float 리터럴(1.0f vs 1.0).
4. 디지털 필터: 이동 평균(링 버퍼 + 합), 1차 IIR 저역 통과(y += α(x − y)), 중앙값 필터, 샘플링 주기의 의미. 입력 수열에 대한 출력으로 검증.
5. PID 제어기: 이산 PID 식, 구조체 상태, 적분 와인드업 방지(클램핑), 출력 포화, 측정값 미분(미분 킥 방지), dt. PC 시뮬레이션: 간단한 1차 시스템 모델에 PID를 걸어 응답을 출력(결정적이므로 run 검증 가능) — 모터 속도 제어/크루즈 컨트롤 연결.
6. CAN 메시지 파싱: 프레임 구조(ID, DLC, data[8]), 리틀 엔디안(Intel) 신호 추출(시작 비트, 길이) 함수, 물리값 = raw × factor + offset, 부호 있는 신호, DBC 개념. Motorola(빅 엔디안) 순서는 개념과 주의점만(복잡하므로 정확히 설명할 수 없는 부분은 쓰지 말 것).
7. C++로 임베디드 코드 구조화: 클래스로 드라이버 캡슐화(Gpio, Uart, Motor), RAII(인터럽트 잠금 가드), 생성자에서 하드웨어 초기화 시 주의(정적 초기화 순서), 가상 함수 비용(간접 호출 + vtable), 템플릿(컴파일 시간 다형성), constexpr(컴파일 시간 룩업 테이블), enum class, namespace, -fno-exceptions -fno-rtti, std::array.
8. 리눅스/젯슨/ROS 2 쪽 모던 C++: unique_ptr/shared_ptr, 람다와 std::function(콜백), auto/범위 for, std::thread/mutex 맛보기, 이동(move) 개념 간단히, CMake 이름만.
9. 코딩 표준과 품질: MISRA C 개요(대표 규칙 예), 정적 분석, -Wall -Wextra -Werror, 하드웨어 의존성 분리 후 PC에서 단위 테스트.
10. C#은 언제 필요한가: PC 툴(시리얼 모니터, 테스트 장비 GUI, 데이터 로거), 산업용 HMI, Unity 시뮬레이션 — C++ 기초가 있으면 빠르게 익힌다. 우선순위 C → C++ → (필요시) C#/Python.
11. 다음 단계 로드맵: 프로젝트 제안(레지스터 직접 LED/UART, 링 버퍼 + 명령 파서, PID 모터 제어, CAN 통신, ROS 2 노드), 학습 순서, 포트폴리오 팁(코드 + README + 측정 그래프).
