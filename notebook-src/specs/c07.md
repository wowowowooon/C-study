## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. char = 1바이트 정수, ASCII 핵심값('0'=48, 'A'=65, 'a'=97, ' '=32, '\n'=10), cout << 'A' vs cout << (int)'A', 'a' + 1 → 98, (char)('a' + 1) → 'b', 문자 ↔ 숫자(c - '0', d + '0'), 알파벳 순번(c - 'a').
2. <cctype>: isdigit, isalpha, isupper, islower, isspace, toupper, tolower — 반환형이 int라 cout << toupper(c)는 숫자가 출력됨(실행으로 보여 주기) → (char)로 받기.
3. 대소문자 변환 직접 구현(c - 'a' + 'A').
4. std::string 기본기: 생성(string(5, '*')), size/length, s[i], front/back, 순회(for (char c : s), 수정은 char&), 비교(== , < 사전순, 'Z' < 'a'), 이어 붙이기(+, +=, push_back), s + 'c'는 OK, "a" + "b"는 에러(data-check=error).
5. 부분 문자열 substr(pos, len): 두 번째 인자는 '길이'(끝 위치 아님), pos만 주면 끝까지, 범위 밖 pos는 예외.
6. 찾기: find → 위치 또는 string::npos, if (s.find(x) != string::npos), find(x, start), rfind.
7. 수정: insert, erase(pos, len), replace(pos, len, str), 모든 등장 치환 루프. 특정 문자 제거는 새 문자열을 만드는 쪽이 쉽고 빠르다.
8. 숫자 ↔ 문자열: to_string, stoi, stoll, stod, "0012" → 12.
9. 뒤집기: reverse(s.begin(), s.end())(<algorithm>; begin/end는 11장에서 자세히 — 지금은 '문자열 전체'라는 뜻), 직접 뒤집기(양 끝 swap).
10. 공백으로 나누기: istringstream(<sstream>)으로 단어 읽기, getline(ss, token, ',')로 구분자 나누기, 직접 파싱.
11. 입력과 문자열: cin >> s(공백 전까지) vs getline(cin, s).
12. C 문자열 미리보기: char s[] = "hi"는 {'h', 'i', '\0'} 3바이트, '\0'으로 끝 표시, strlen. 9장·29장에서 깊게.
13. 성능: s = s + c(매번 새 문자열을 만들어 느림) vs s += c.

## Confusions you MUST address explicitly (each in a .pen box or a quiz)
- 'a' vs "a"
- substr 두 번째 인자
- find 결과를 -1과 비교하는 습관(npos 비교 권장)
- toupper 출력이 숫자
- "10" < "9" (사전순)
- 한글은 UTF-8에서 글자당 여러 바이트라 size()가 글자 수가 아님
- s[s.size()] 접근
