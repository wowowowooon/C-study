## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 왜 반복문인가: 같은 출력 5번을 복사하는 것과 비교.
2. while: 조건 → 본문 → 다시 조건, 카운터 변수, 무한 루프와 탈출. .emb: 펌웨어 main의 while(1) 슈퍼 루프.
3. for: 초기식; 조건식; 증감식 — 실행 순서를 trace 표로 한 단계씩(i 값, 조건 결과, 출력). for ↔ while 바꿔 쓰기, 루프 변수의 범위(scope).
4. 반복 횟수 정확히 세기: i < n 은 n번, i <= n 은 n+1번, 1부터 n까지, 거꾸로, 2씩 증가. off-by-one 오류 찾는 법(작은 n으로 손 실행).
5. do-while(최소 1번 실행), 쓰임이 드물다는 점.
6. break / continue 차이, 중첩 루프에서 break는 가장 안쪽만 빠져나간다, 플래그 변수로 바깥까지 빠져나가기.
7. 중첩 반복: 구구단, 별 찍기(직각삼각형 120823), 행/열 개념, 반복 횟수 n × m.
8. 반복 패턴 모음(코딩테스트 필수): 누적 합(sum 초기화 위치!), 개수 세기, 최댓값/최솟값(초기값 선택), 자릿수 분리(while (n > 0) { d = n % 10; n /= 10; } — n = 0일 때 주의), 약수 찾기(1..n → i * i <= n 개선), 소수 판정(2..√n), 조건 만족까지 반복(while), 시뮬레이션(콜라츠).
9. 무한 루프/시간 초과 원인: 조건이 계속 참, 증감 누락, 오버플로로 음수가 되어 무한 루프(콜라츠 추측 12943의 int 오버플로 함정 → long long).
10. 반복문과 출력 형식: 마지막 공백/줄바꿈 처리.
11. 변수 선언 위치: 누적 변수는 루프 밖에, 매번 새로 필요한 변수는 안에.

## Confusions you MUST address explicitly (each in a .pen box or a quiz)
- for (...); { } 세미콜론
- 조건에 = 사용
- 루프 변수를 루프 밖에서 쓰기
- 루프 본문에서 루프 변수 수정
- unsigned 카운터로 거꾸로 돌면 무한 루프(i >= 0 은 항상 참)
- 실수로 루프 카운터(x != 1.0)
- sum을 루프 안에서 0으로 초기화

## Embedded connections to use (.emb boxes, only where natural)
- 슈퍼 루프 구조(while(1) { 센서 읽기; 계산; 출력; })
- 폴링 루프로 플래그 기다리기(while (!(USART1->SR & RXNE)) {}) — volatile은 30장
- for 문으로 만든 지연 루프가 나쁜 이유(최적화로 사라질 수 있음, 클럭 의존)
