## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 산술 연산자 + - * / %: 정수 나눗셈(몫), 나머지, 음수의 / 와 %(C++11부터 0 쪽으로 버림: -7/2 = -3, -7%2 = -1 — 실행으로 확인), 0으로 나누기(정수는 정의되지 않은 동작/프로그램 종료, 실수는 inf), %는 정수 전용(실수는 fmod).
2. 몫과 나머지의 쓰임새 모음: 짝/홀(n % 2), 배수(n % k == 0), 마지막 자리(n % 10), 자리 떼기(n / 10), 초 → 분:초, 올림 나눗셈 (a + b - 1) / b(양수일 때만), 순환((x % m + m) % m과 각도 정규화 — 340206 연결).
3. 대입과 복합 대입: =, +=, -=, *=, /=, %=. 대입식도 값을 가진다(그래서 if (a = 5)가 컴파일된다 — 4장 경고 예고).
4. 증감 연산자 ++, --: 전위/후위 차이를 값 사용 시점으로 설명(trace 표), 단독으로 쓰면 같다, 한 식에서 같은 변수를 여러 번 바꾸지 않기(-Wall 경고/혼란).
5. 비교 연산자 == != < <= > >=: 결과는 bool(cout하면 1/0, boolalpha로 true/false), = vs ==, 실수 == 비교 주의.
6. 논리 연산자 && || !: 진리표, 단축 평가(왼쪽에서 결과가 정해지면 오른쪽은 실행 안 함 — b != 0 && a / b > 1 예).
7. 연산자 우선순위와 결합 방향: 핵심만 표로(! → * / % → + - → << >> → < <= > >= → == != → & → ^ → | → && → || → ?: → = +=). 헷갈리면 괄호. a + b * c, !a == b, 7 / 2 * 2 vs 7 * 2 / 2 예.
8. 수학 함수 <cmath>: abs(정수) / fabs, sqrt(double 반환), pow(double 반환 — 정수 거듭제곱은 곱셈으로; pow 결과를 정수로 바꿀 때 오차 위험), round/floor/ceil, max/min(<algorithm>, 두 인자 타입이 같아야 함 — max(1, 2LL)은 컴파일 에러: data-check=error로).
9. 비트 연산 맛보기: & | ^ ~ << >> 를 2진수로(bitset<8>로 출력해서 보여 주기), n & 1 로 홀짝, 1 << k = 2^k, ^는 거듭제곱이 아니다(2^3 == 1). 깊은 내용은 27장·29장.
10. 오버플로 다시: 곱셈 중간 결과(1000000 * 1000000), long long으로 바꾸려면 곱하기 '전에' 캐스트.
11. 형 변환과 연산: int / int → int, int / double → double, 실수 나눗셈 후 버림(120806 두 수의 나눗셈의 핵심).

## Confusions you MUST address explicitly (each in a .pen box or a quiz)
- 7 / 2 * 2 = 6 vs 7 * 2 / 2 = 7
- 음수 나머지
- ^ 는 XOR
- sqrt/pow는 double을 돌려줌
- max(int, long long) 에러
- i = i++ 같은 코드
- 올림 나눗셈 공식은 양수에서만
- 정수 0으로 나누기

## Embedded connections to use (.emb boxes, only where natural)
