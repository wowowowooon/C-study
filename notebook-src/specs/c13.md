## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 구현 문제란: 알고리즘보다 '정확히 옮기기'. 요구사항 목록으로 쪼개기, 단계별 함수.
2. 격자 다루기: 좌표계(행 r은 아래로 증가, 열 c는 오른쪽), dx/dy 방향 배열(4방향, 8방향), 범위 검사 함수, 벽/장애물, 이동 시뮬레이션, 방향 회전((d + 1) % 4, (d + 3) % 4).
3. 문자열 파싱: "HH:MM" → 분, "YYYY.MM.DD" → 일수(문제의 가정을 따르기 — 예: 한 달 28일), 명령 문자열, stringstream/substr/stoi 조합, split 함수 직접 구현.
4. 상태 관리: 변수/구조체로 상태 표현, 시간(턴) 단위 루프, 이벤트 순서.
5. 행렬 조작: 90도 회전, 테두리 회전, 전치, 복사본을 쓰는 이유(동시 갱신 문제).
6. 스택/큐를 이용한 시뮬레이션(크레인 인형뽑기).
7. 구현 실수 줄이기: 예제를 손으로 시뮬레이션, 상태 출력 함수(printGrid), 0/1 기준 통일, 이름 짓기.
8. 카카오 스타일 긴 문제 읽기: 표로 정리, 예외 조건 체크리스트.
