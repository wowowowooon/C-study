## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 왜 배열인가(변수 100개 vs 배열 하나). C 배열 int a[5]: 메모리에 연속 배치(.mem 그림, 4바이트 간격 주소), 인덱스 0부터 n-1, 초기화 {1, 2, 3}, {0}, 크기는 컴파일 시간 상수.
2. 범위 밖 접근 = 정의되지 않은 동작(컴파일러가 막지 않음), 옆 변수를 덮어쓰는 버그 데모(data-check=ub, 결과 보장 없음 명시). .emb: 버퍼 오버런 → 스택 손상 → HardFault.
3. 배열 + 반복문: 입력 받기, 합/평균/최대/최소, 선형 탐색, 뒤집기(양 끝 swap), 복사(배열은 = 대입 불가).
4. sizeof(a) / sizeof(a[0])로 길이(함수에 넘기면 안 된다는 것은 9장 예고).
5. std::vector: #include <vector>, push_back, size, [], at(범위 검사 → 예외), front/back, pop_back, empty, clear, 생성 vector<int> v(n), v(n, 7), {1, 2, 3}, 대입·비교 가능(C 배열과 차이).
6. 순회 3가지: 인덱스 for, 범위 기반 for(for (int x : v)), 원소를 바꾸려면 for (int& x : v)('&를 붙이면 원본을 바꾼다' 정도만, 8장·9장에서 자세히).
7. size()의 함정: size_t(부호 없는 정수) → 빈 벡터에서 v.size() - 1이 거대한 수, int와 비교 경고(-Wsign-compare) → (int)v.size() 습관.
8. 함수형 문제의 vector: 매개변수 vector<int> numbers 읽기, vector<int> answer에 push_back 후 return, return {a, b};.
9. 카운팅 배열(빈도 세기): int cnt[10] = {0}; cnt[d]++ — 값의 범위가 작을 때.
10. 2차원 배열: int g[3][4], 행(row)/열(col), 메모리상 행 우선 배치, 이중 for. vector<vector<int>> g(r, vector<int>(c, 0)), g.size() = 행 수, g[0].size() = 열 수.
11. 배열 조작 패턴: 부분 배열(인덱스 범위 복사), 회전(임시 변수), 두 배열 동시 순회(내적), 조건에 맞는 원소만 담기.

## Confusions you MUST address explicitly (each in a .pen box or a quiz)
- a[5]의 마지막 인덱스는 4
- vector<int> v(5) 와 vector<int> v{5} 의 차이
- push_back 뒤 이전 참조/포인터 무효화(짧게 경고, 11장)
- v[i]는 범위 검사를 안 함
- vector<vector<int>> g(r); 후 g[i][j] 접근 크래시
- 빈 벡터 v[0]
- size() - 1 언더플로
