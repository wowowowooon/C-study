## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 선형 탐색 O(n) vs 이분 탐색 O(log n)(업다운 게임), 전제: 정렬.
2. 직접 구현: lo, hi, mid = lo + (hi − lo) / 2(오버플로 방지), lo <= hi 템플릿과 lo < hi 템플릿, 무한 루프 함정.
3. lower_bound/upper_bound: 첫 번째 ≥ x, 첫 번째 > x, 개수 세기(upper − lower), 직접 구현 버전.
4. 매개변수 탐색: '최솟값/최댓값을 구하라' → 'x로 가능한가?' 결정 함수(단조성) → 답의 범위에서 이분 탐색. 입국심사(시간 t 안에 처리 가능 인원 = Σ t / time_i), 징검다리 건너기, 퍼즐 게임 챌린지, 선입 선출 스케줄링.
5. 범위 설정(lo, hi 초기값, long long), 결정 함수 오버플로(합이 n을 넘으면 조기 종료).
6. 실수 이분 탐색(반복 횟수 고정) 간단히.
7. 정렬 + 이분 탐색(순위 검색: 그룹별 점수 정렬 후 lower_bound).
