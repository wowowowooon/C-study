## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. C와 C++의 차이 총정리 표(클래스/참조/오버로딩/STL/namespace 없음, bool은 <stdbool.h>, new/delete 없음, struct 키워드, 헤더 이름 <stdio.h> vs <cstdio>, extern "C"). 펌웨어가 C인 이유(벤더 HAL, 컴파일러 지원, 예측 가능성).
2. printf/scanf 완전 정리: 서식 지정자 표(%d %u %ld %lld %x %X %08X %o %c %s %f %.2f %e %p %%), 폭/정밀도/플래그, 반환값, 불일치 = 정의되지 않은 동작, snprintf로 안전하게 문자열 만들기(UART 출력용).
3. 고정 폭 정수 <stdint.h>: int8_t … uint64_t, uintptr_t, size_t, 왜 필요한가(int 크기는 플랫폼마다), <inttypes.h> PRIu32.
4. 정수 승격과 변환 함정: uint8_t + uint8_t는 int로 계산, char의 부호는 구현 정의, signed/unsigned 비교(-1 < 1u가 거짓 — 실행으로), 부호 확장(int8_t → int32_t), 랩어라운드와 타이머 카운터의 안전한 경과 시간 계산((uint32_t)(now − start) >= period).
5. 비트 연산 완전 정복: 비트 번호, 마스크(1U << n), set(|=), clear(&= ~), toggle(^=), test(&), 필드 읽기 ((reg >> pos) & mask)와 쓰기 (reg = (reg & ~(mask << pos)) | (val << pos)), 1 << 31 함정(1U), 시프트 범위 초과는 정의되지 않은 동작, 음수 오른쪽 시프트는 구현 정의, 비트 세기(Kernighan), 2의 보수.
6. 엔디안: little vs big, 바이트 배열 ↔ 정수 조립(센서 레지스터 MSB/LSB → int16_t: (int16_t)((hi << 8) | lo)), 엔디안 판별 코드, 이식성 있는 조립.
7. 매크로와 전처리기: #define 상수/함수형 매크로(괄호 함정 #define SQ(x) x * x), do { } while (0), #ifdef/#ifndef/#if, 헤더 가드, 조건부 컴파일(디버그 로그), const/enum/inline으로 대체하는 이유.
8. <string.h>: strlen, strcpy/strncpy(널 종료 함정), strcmp(0이면 같다!), strcat, strchr/strstr, memset/memcpy/memmove(겹침), sprintf vs snprintf, atoi vs strtol(에러 처리), 버퍼 오버플로와 안전한 패턴.
9. 실습(직접 구현 + 정답): 비트 조작 함수 세트, 바이트 조립/분해, UART 명령 파서("LED 1 ON"), itoa 구현.
