## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 변수 = 이름 붙은 메모리 칸(.mem 그림: 주소, 값, 이름). 선언, 초기화, 대입. = 는 '같다'가 아니라 '오른쪽 값을 왼쪽 칸에 넣는다'. x = x + 1 의 의미를 단계별로.
2. 초기화하지 않은 지역 변수 = 쓰레기 값(정의되지 않은 동작, data-check="ub")→ 항상 초기화. 전역 변수는 0으로 시작(.emb: 스타트업 코드가 .bss를 0으로 채우기 때문).
3. 기본 자료형 표: bool, char, short, int, long long, unsigned 계열, float, double — 크기(sizeof로 직접 출력), 범위, 언제 쓰나. 64비트 리눅스 g++ 기준이라고 명시, int 크기는 플랫폼마다 다를 수 있다(AVR은 2바이트) → 29장 stdint.
4. 정수 오버플로: <climits>의 INT_MAX, INT_MAX + 1은 signed overflow = 정의되지 않은 동작(ub 데모, 결과를 보장하지 않는다고 명시), unsigned는 0으로 돌아감(정의됨). 코딩테스트에서 long long을 써야 할 때(10^9 × 10^9, 큰 합계), 리터럴 접미사 LL.
5. 실수: double 기본, float는 정밀도가 낮음, 0.1 + 0.2 == 0.3 이 거짓인 이유(2진수로 정확히 못 나타냄), 실수 비교 주의, 출력 자릿수 cout << fixed << setprecision(2) (<iomanip>).
6. char 맛보기: 'A'는 사실 숫자 65(ASCII). 'A'(문자 1개, 작은따옴표) vs "A"(문자열, 큰따옴표). 자세한 건 7장.
7. string 기본: string s = "hello"; + 로 이어 붙이기. 숫자와 문자열은 다른 타입: 3 + 10 = 13 vs string("3") + "10" = "310", 그리고 "3" + "10"은 컴파일 에러(리터럴끼리는 + 불가 — 이유는 7장/9장). PCCE 250133 연결.
8. 형 변환: 암시적 변환(int → double), 정수끼리 나누면 정수(7/2 = 3, 3장에서 자세히), static_cast<double>(7) / 2, double → int는 버림(반올림 아님, 음수는 0 쪽으로), C 스타일 (int)x, bool ↔ int.
9. const와 매직 넘버 피하기, constexpr은 한 줄 소개. auto(타입 추론)는 소개만 하고 처음엔 타입을 직접 쓰라고 권장.
10. 입력 cin 자세히: cin >> a >> b, 공백·줄바꿈으로 구분, getline(cin, s)(공백 포함 한 줄), cin >> 다음 getline 함정(남은 '\n', cin.ignore()로 해결) — data-stdin으로 실제 실행 검증.
11. C에서는: scanf("%d", &a), printf 서식 지정자 표(%d %lld %f %c %s %%), &는 '변수의 위치(주소)를 알려 준다'고만 하고 9장에서 설명, 서식과 타입 불일치는 정의되지 않은 동작.
12. 함수형(solution) 문제 템플릿 읽는 법: int solution(int num1, int num2) { int answer = 0; return answer; } — 괄호 안 = 채점기가 넣어 주는 값(매개변수), return = 정답을 돌려줌, main이 없는 이유(채점기가 main을 갖고 solution을 호출). '코드 실행'에서 cout은 디버깅용일 뿐 정답은 return. 함수 자체는 8장.

- 2147483647 + 1
- cin >> 후 getline이 빈 줄을 읽음
