## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. if 문의 구조와 실행 흐름(그림 또는 단계), 조건식은 bool, 블록 { }와 들여쓰기.
2. if-else, else if 사다리: 위에서부터 첫 번째 참인 블록만 실행, 순서가 결과를 바꾼다, 범위 나누기(점수 → 학점)와 경계값(< vs <=) 테스트 습관.
3. 중첩 if vs && 로 합치기, dangling else(중괄호 생략의 위험) → 항상 중괄호 권장.
4. 조건식의 함정: if (x = 5)(항상 참, -Wall 경고를 실제로 보여 주기), if (0 < x < 10)(C++에선 (0 < x) < 10이라 항상 참 — 실행으로 증명), 실수 비교(fabs(a - b) < 1e-9), 정수를 조건으로 쓰면 0만 거짓, if (x > 0); 뒤 세미콜론(빈 문장).
5. 논리 연산자로 조건 조합: 윤년 판정((y % 4 == 0 && y % 100 != 0) || y % 400 == 0), 삼각형 성립 조건.
6. switch: 정수/문자만 가능, case와 break, fall-through(일부러 쓸 땐 [[fallthrough]]), default, case 안에서 변수 선언하려면 { }, switch vs if 선택 기준.
7. 삼항 연산자 cond ? a : b: 짧은 선택에만, 중첩 금지, 두 결과 타입이 섞이면 넓은 타입으로.
8. 문자열로 분기: string == "Korea"(PCCE 나이 계산), 사전순 비교 <는 7장에서.
9. early return 패턴: solution 안에서 if (조건) return 값; (8장에서 함수와 함께 자세히).
10. 조건문 디버깅: 경계값(0, 음수, 같은 값, 최대값)으로 테스트하는 습관.

## Confusions you MUST address explicitly (each in a .pen box or a quiz)

- if (...); 세미콜론
- = vs ==
- 0 < x < 10
- switch break 누락
- else if 순서가 바뀌면 결과가 달라짐
- 문자열 비교는 대소문자를 구분
