## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 그리디란: 매 순간의 최선이 전체 최선을 보장할 때만. 거스름돈 예(500/100/50/10은 성립, 동전 {1, 3, 4}로 6 만들기는 실패 → DP).
2. 정당성 확인: 교환 논법 직관, 반례 찾기 습관.
3. 정렬 + 그리디: 구간 스케줄링(끝나는 시간 기준: 단속카메라, 요격 시스템), 숫자 게임(정렬 + 투 포인터).
4. 스택 그리디: 큰 수 만들기(앞자리를 크게).
5. 수학적 그리디: 최고의 집합(n/s 균등 분배), 기지국 설치(빈 구간마다 ceil(len / (2w + 1))).
6. 조이스틱(상하는 글자별 최소, 좌우 이동은 경로 비교 — 함정 많음).
7. 택배 배달과 수거하기(먼 곳부터), 마법의 엘리베이터(자릿수별 올림/내림 결정).
8. 체육복(여벌 + 도난 겹침을 먼저 처리), 덧칠하기.
9. 그리디 vs DP 판단 기준.
