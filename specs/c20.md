## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 그래프 용어: 정점, 간선, 방향/무방향, 가중치, 연결 요소, 사이클, 차수.
2. 표현: 인접 행렬(n² 메모리, 연결 확인 O(1)) vs 인접 리스트 vector<vector<int>>(O(V + E)), 간선 목록 → 인접 리스트(무방향은 양쪽), 0/1 기반 번호.
3. DFS: 재귀 구현, visited, 방문 순서 trace(스택 그림), 명시적 stack 구현, 연결 요소 개수.
4. BFS: queue, 방문 표시는 '넣을 때'(꺼낼 때 표시하면 중복 삽입), dist 배열 = 가중치 없는 최단 거리, 레벨별 처리.
5. 격자 그래프: 2차원 visited, dx/dy, 범위/벽 검사, 최단 거리(게임 맵), 영역 개수/크기(무인도 여행, 컬러링북), 경유지(미로 탈출: 시작 → 레버 → 출구 두 번 BFS), 미끄러지는 이동(리코쳇 로봇: 벽까지 한 번에).
6. DFS vs BFS 선택표.
7. 상태 공간 탐색: 타겟 넘버(+/− 선택 트리 DFS).
8. 석유 시추: 영역 라벨링 후 열별 합산(효율성 포인트).
9. 재귀 DFS의 스택 깊이(1000 × 1000 격자 위험 → BFS/명시적 스택).
