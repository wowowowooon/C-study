## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 완전탐색 판단: 경우의 수 계산(조합 C(n, r), 순열 P(n, r), 부분집합 2ⁿ) → 대략 10⁷–10⁸ 이하면 가능.
2. 반복문 탐색: 2중/3중 for(삼총사), 범위 줄이기(카펫: 약수 쌍).
3. 재귀로 조합/순열/중복순열: 선택 배열, visited, 재귀 트리 그림, 템플릿 dfs(depth), 순서를 고려하는지에 따라 달라지는 코드.
4. next_permutation: 정렬 후 do-while, 중복 원소 처리.
5. 비트마스크 부분집합: for (mask = 0; mask < (1 << n); mask++), (mask >> i) & 1. .emb: 비트 플래그와 같다.
6. 백트래킹: 가지치기(조건 위배 시 즉시 return), N-Queen(열/대각선 배열), 상태 복구(visited 되돌리기).
7. 숫자/문자열 조합: 소수 찾기(만든 수를 set으로 중복 제거 후 판정), 모음 사전(사전순 생성), 수식 최대화(연산자 우선순위 순열).
8. 그래프 끊기 완전탐색(전력망: 간선 하나씩 제거 후 DFS로 개수 세기 — 작은 DFS를 '20장에서 자세히'라고 하고 사용).
9. 양궁대회: 화살 배분 탐색과 동점 규칙(낮은 점수를 더 많이 맞힌 경우).
10. 한계: n = 20 부분집합은 가능, n = 30은 위험.
