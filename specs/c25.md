## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. DP란: 최적 부분 구조 + 중복 부분 문제 → 작은 문제의 답을 저장해 재사용.
2. 피보나치로 3단계: 재귀 O(2ⁿ) → 메모이제이션(top-down) O(n) → 타뷸레이션(bottom-up), 공간 최적화(변수 2개).
3. DP 설계 4단계: 상태 정의(dp[i] = …를 한 문장으로) → 점화식 → 초기값 → 계산 순서/답의 위치. 표 그리기.
4. 1차원 DP: 멀리 뛰기/2 × n 타일링(피보나치 변형, % 연산), 3 × n 타일링(짝수만, 점화식 유도), 스티커 모으기(2)(원형 → 첫 장을 뗀 경우/안 뗀 경우 두 번), 숫자 변환하기(dp[x] 최소 연산 횟수, BFS와 비교).
5. 2차원 DP: 정수 삼각형, 등굣길(경로 수, 물웅덩이, % 1,000,000,007), 땅따먹기(같은 열 연속 금지), 가장 큰 정사각형 찾기(min(위, 왼쪽, 대각선) + 1).
6. 동전/배낭 유형: 거스름돈(경우의 수 — 동전 루프가 바깥이면 조합, 금액 루프가 바깥이면 순열: 중요한 함정을 실행 결과로 비교), 0/1 배낭 개념.
7. 문자열 DP: 가장 긴 팰린드롬(중심 확장 O(n²) 또는 dp[i][j]), LCS 개념.
8. 집합 DP: N으로 표현(dp[k] = N을 k번 써서 만들 수 있는 수의 set).
9. 다차원 상태 + 최소 시간: 코딩 테스트 공부(dp[alp][cop]) — 도전.
10. DP 디버깅: dp 표 출력, 작은 입력 손계산과 비교.
