## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 정렬이 필요한 순간(탐색, 그리디, 중복 처리, 순위).
2. 원리 이해를 위해 직접 구현: 선택/버블/삽입 정렬(O(n²), trace), 병합 정렬(분할 정복, O(n log n), 안정 정렬), 퀵 정렬 개념(피벗, 평균 O(n log n), 최악 O(n²)). 면접 단골.
3. std::sort: 사용법, 내림차순(greater<int>(), rbegin/rend), 부분 범위, O(n log n).
4. 비교 함수 규칙(strict weak ordering): a가 b보다 '앞'일 때만 true, 같으면 false. <= 를 쓰면 정의되지 않은 동작/크래시 가능 — 중요한 함정. 비교 함수/람다/operator< 세 가지 방법.
5. 다중 기준 정렬: 점수 내림차순, 같으면 이름 오름차순 — if 분기, tie/pair 비교 트릭(make_pair(-score, name)).
6. stable_sort: 동점이면 원래 순서 유지(파일명 정렬).
7. 인덱스 정렬: pair<값, 인덱스>로 원래 위치 기억, 순위 매기기.
8. 문자열 정렬: 사전순, 대소문자, 길이순, 숫자 문자열 함정("10" < "9"), 가장 큰 수(a + b > b + a).
9. 카운팅 정렬(값 범위가 작을 때 O(n + k)) — 숫자 짝꿍.
10. 정렬 후 활용: 인접 비교, 투 포인터 예고, 그리디 예고, k번째 원소(nth_element 소개).
