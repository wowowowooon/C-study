## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. STL이란: 컨테이너 + 반복자 + 알고리즘. 코딩테스트의 무기.
2. 반복자(iterator): begin()은 첫 원소, end()는 마지막 '다음'(반열림 구간 [begin, end)), *it, ++it, it - v.begin()(인덱스), auto. 반복자 무효화(push_back/erase 후 기존 반복자/참조/포인터 금지, 순회 중 erase는 it = v.erase(it)).
3. vector 심화: insert, erase(pos)/erase(first, last), resize vs reserve, assign, 앞에서 지우기는 느리다(O(n) — 12장에서 정식 표기).
4. <algorithm> 필수 함수: sort, reverse, max_element/min_element(반복자 반환), find, count, count_if, accumulate(<numeric>, 초기값 0이면 int로 합산 → 0LL), fill, unique + erase(정렬 후 중복 제거), lower_bound/upper_bound(정렬된 범위 — 22장), next_permutation(정렬 후 모든 순열), swap, max/min({a, b, c}).
5. 람다 기초: [](int a, int b) { return a > b; }, 캡처 [&], [=] 간단히, sort/count_if와 함께.
6. stack: push/pop/top/empty/size — pop()은 값을 돌려주지 않는다, 빈 stack의 top/pop은 정의되지 않은 동작.
7. queue: push/pop/front/back. deque: 양쪽 push/pop, 인덱스 접근.
8. priority_queue: 기본 최대 힙(top = 최댓값), 최소 힙 priority_queue<int, vector<int>, greater<int>>, pair는 first 기준. 비교자 방향이 sort와 반대로 느껴지는 이유는 17장.
9. set/multiset: 자동 정렬 + 중복 제거(multiset은 중복 허용), insert/erase/find/count, 정렬 순서 순회. unordered_set: 해시, 순서 없음.
10. map/unordered_map: key → value, m[key]는 없으면 기본값으로 '생성'된다(실행으로 증명), count/find로 존재 확인, 순회 for (auto& [k, v] : m), map은 key 정렬 순서, 빈도 세기 m[x]++.
11. std::array 소개(고정 크기, 임베디드에서도 OK).
12. 컨테이너 선택 가이드 표(주요 연산의 속도: 빠름/느림 + O 표기 맛보기 — 정식 설명은 12장).

## Confusions you MUST address explicitly (each in a .pen box or a quiz)
- end()는 마지막 원소가 아님(*v.end() 금지)
- max_element는 반복자를 돌려줌
- accumulate 초기값 타입
- map[]의 부작용
- unordered_map 순회 순서를 기대
- set 원소는 직접 수정 불가
- stack.pop()의 반환값
- 순회 중 erase
- unique는 정렬 후에만 의미
