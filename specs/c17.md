## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 필요한 순간: 매번 최솟값/최댓값을 꺼내야 할 때(매번 정렬하면 느림).
2. 힙 구조: 완전 이진 트리, 배열 표현(0-based: 자식 2i+1, 2i+2 / 부모 (i-1)/2), 힙 성질, push(sift up)/pop(sift down) trace, O(log n), 최소 힙 직접 구현.
3. priority_queue: 최대 힙 기본, 최소 힙 greater, pair/tuple(first 기준 → second), 음수 트릭, 사용자 정의 비교자(struct cmp { bool operator()(…) const }) — 'true면 a가 b보다 우선순위가 낮다(뒤로 간다)'로 이해, sort와 반대로 느껴지는 이유.
4. 패턴 1 가장 작은 두 개 합치기(더 맵게).
5. 패턴 2 상위 k개 유지(명예의 전당: 크기 k 최소 힙).
6. 패턴 3 그리디 + 힙(디펜스 게임: 무적권은 가장 큰 적에게, 야근 지수: 최댓값 줄이기).
7. 패턴 4 시간 순 이벤트 시뮬레이션(디스크 컨트롤러: 요청 시간 정렬 + 작업 시간 최소 힙, 호텔 대실: 종료 시간 최소 힙 = 필요한 방 수).
8. 패턴 5 최댓값과 최솟값을 동시에 → multiset(이중우선순위큐).
9. 참고: make_heap/push_heap/pop_heap.
