## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 재귀적 사고 3단계: 함수의 정의를 믿기, 종료 조건, 작은 문제로 쪼개기. 하노이 탑(이동 경로 기록, 2ⁿ − 1번).
2. 분할 정복: 쪼개기 → 풀기 → 합치기, 병합 정렬 복습, 고속 거듭제곱(a^b mod m을 O(log b) — 재귀와 반복(비트) 버전).
3. 쿼드트리 압축(영역이 모두 같은지 검사 후 4분할).
4. k번째 순열(줄 서는 방법: 팩토리얼 진법).
5. 자기유사 구조(유사 칸토어 비트열: 5진수 관찰).
6. 재귀 정의를 그대로 코드로(괄호 변환).
7. 트리 기초: 루트/부모/자식/리프/깊이/서브트리, 이진 트리, 표현(배열, 구조체 + 포인터, 인덱스), 전위/중위/후위 순회 재귀 구현, 레벨 순서(BFS 예고), 이진 탐색 트리(BST) 삽입/탐색.
8. 트리 문제: 길 찾기 게임(좌표로 BST 구성 + 전위/후위), 표현 가능한 이진트리(포화 이진트리 크기로 맞추고 재귀 검사).
9. 재귀의 비용: 깊이가 n이면 스택 오버플로 위험, 반복으로 바꾸기(명시적 스택).
