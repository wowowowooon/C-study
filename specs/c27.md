## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 진법: 10진 → n진(나머지를 거꾸로), n진 → 10진(호너 방법), 문자 '0'–'9', 'A'–'F', 3진법 뒤집기, k진수 소수, n진수 게임, 124 나라(0이 없는 진법), bitset과 __builtin_popcount.
2. GCD/LCM 응용: 멀쩡한 사각형(w + h − gcd(w, h)), 숫자 카드 나누기(배열 전체 gcd).
3. 소수: √n 판정, 에라토스테네스의 체 복습, 소인수분해, 약수 개수(억억단: 체처럼 약수 개수 누적 + 구간 최대 전처리).
4. 모듈러 연산: (a + b) % m, (a * b) % m, 뺄셈 음수 처리 ((a − b) % m + m) % m, 나눗셈은 그대로 안 됨(모듈러 역원은 개념만), 고속 거듭제곱 복습.
5. 조합론: nCr 파스칼 삼각형 DP, 오버플로.
6. 비트 테크닉: 확인/설정/해제/토글, x & −x(최하위 1비트), x & (x − 1)(마지막 1 제거, 2의 거듭제곱 판정), popcount, 2개 이하로 다른 비트(짝수/홀수 관찰), 비밀지도(OR).
7. 좌표/기하: 점 찍기(원 안의 격자점 — sqrt 오차 대신 정수 연산), 두 원 사이의 정수 쌍.
8. 실수 정밀도: double 비교, sqrt 결과를 정수로 바꿀 때 보정, 가능하면 정수로만 풀기.
9. 규칙 찾기 접근법: 작은 n으로 표 만들기.
