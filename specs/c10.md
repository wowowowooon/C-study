## Topics to teach (in this order; each normally becomes one or more numbered h3 sections)
1. 왜 묶나: 이름 배열과 점수 배열을 따로 관리하는 불편 → struct.
2. struct 정의/변수/멤버 접근(.), 초기화({…}), 구조체 배열과 vector<Student>, 함수에 넘기기(const 참조), 포인터로 접근(->), 구조체 복사.
3. 멤버 함수(데이터 + 동작), const 멤버 함수 간단히.
4. class: public/private, 캡슐화의 이유(setSpeed가 범위를 검사), getter/setter, struct와 class의 차이(기본 접근 지정자뿐), 관례.
5. 생성자: 기본/매개변수 생성자, 멤버 초기화 리스트, 생성자 오버로딩. 소멸자(객체가 사라질 때 자동 호출) → RAII 개념(vector가 메모리를 자동으로 돌려주는 이유).
6. 객체의 수명과 범위: 생성/소멸 순서를 출력으로 확인하는 예제.
7. 연산자 오버로딩 맛보기: operator<(정렬 기준), operator==, operator<<(출력).
8. pair와 tuple: first/second, make_pair, {a, b}, pair 비교는 first 먼저 그다음 second(사전식) → 정렬에 유용, tuple/get/tie, 구조적 바인딩 auto [a, b](C++17).
9. sort 맛보기: sort(v.begin(), v.end())와 비교 함수/람다(동점 처리) — 11장·14장에서 깊게, 여기서는 '구조체를 원하는 기준으로 정렬'에 집중.
10. C의 구조체: struct 키워드 필요, typedef struct {...} Name;, 멤버 함수 없음(함수 포인터로 흉내 — 30장).
